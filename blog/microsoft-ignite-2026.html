Executive overview

The endpoint story is a shift from configuration to continuous governance and remediation.

Microsoft is connecting endpoint signals, security agents and management actions: discover what runs, verify device state, deliver changes faster, reduce exposure, keep applications and operating systems current, recover quickly and apply the same patterns to eligible servers and Cloud PCs.

Release reality: production-ready value is concentrated in Defender local agent discovery and runtime protection, Microsoft Perception, Windows Autopatch, Windows 11 platform security, Intune responsiveness (enrollment-time grouping, IME push, event-driven compliance, unified Sync, post-ESP app check) and selected Windows 365 controls. Many of the more transformative capabilities—agent compliance, vulnerability-remediation agents, broad application auto-updating, server management and advanced Cloud PC scenarios—remain in preview or have staged availability.
GovernLocal AI agents become manageable endpoint workloads with discovery, compliance, containment and runtime controls.
Reduce exposurePerception and Intune connect prioritized security findings to app/OS remediation and temporary shielding.
Act fasterPush delivery, event-driven compliance, unified Sync and fresher reporting shorten the gap between intent, device action and evidence.

01

Unified discovery of agents on managed devices

New / integrated
Defender discovery GA; registry and network discovery in preview

Previous state

Agent discovery signals were spread across security, identity and endpoint tools, making unsanctioned local agents difficult to inventory as one estate.

→

New state

Defender discovers more than 60 local AI agents and their MCP servers on managed Windows and macOS devices, mapped to device and user. Agent 365 adds these local and shadow agents to the Agent registry; Global Secure Access adds network-level discovery.

What improved: Creates a shared inventory and governance starting point instead of requiring endpoint teams to reconcile separate signals.

IT admin value

Improves visibility, supports policy targeting and reduces time spent assembling an agent inventory.

End-user value

Indirect: approved tools can be enabled with clearer guardrails while risky agents can be addressed consistently.

Availability: Local agent discovery in Microsoft Defender is GA. Shadow AI discovery in the Agent 365 registry and network discovery in Global Secure Access are preview.

02

Software compliance policy for unsanctioned agents

New
Public preview

Previous state

Intune compliance primarily evaluated device settings and health; an unwanted agent did not automatically make a Windows device noncompliant.

→

New state

Admins identify restricted applications (the published example uses MSI product codes). Intune can mark a Windows device noncompliant; Entra Conditional Access can then block corporate resources and guide the user to remove the agent.

What improved: Turns local software presence into an access-control signal and closes the loop from detection to conditional access.

IT admin value

Provides policy-based enforcement without creating a separate access system.

End-user value

Users receive a remediation path and regain access after removing the unsanctioned software.

Availability: Public preview as of 17 November 2026.
Implementation note: Validate matching for portable binaries, package managers and non-MSI agents before enforcing; begin with Conditional Access in report-only mode.
