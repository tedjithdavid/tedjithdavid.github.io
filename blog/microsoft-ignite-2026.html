Executive overview

The endpoint story is a shift from configuration to continuous governance and remediation.

Microsoft is connecting endpoint signals, security agents and management actions: discover what runs, verify device state, deliver changes faster, reduce exposure, keep applications and operating systems current, recover quickly and apply the same patterns to eligible servers and Cloud PCs.

Release reality: production-ready value is concentrated in Defender local agent discovery and runtime protection, Microsoft Perception, Windows Autopatch, Windows 11 platform security, Intune responsiveness (enrollment-time grouping, IME push, event-driven compliance, unified Sync, post-ESP app check) and selected Windows 365 controls. Many of the more transformative capabilities—agent compliance, vulnerability-remediation agents, broad application auto-updating, server management and advanced Cloud PC scenarios—remain in preview or have staged availability.

01

Unified discovery of agents on managed devices

NewHelps IT adminsDefender discovery GA; registry and network discovery in preview

AI tools like Claude Code or ChatGPT Desktop can now be found on your managed devices in one place. Microsoft Defender detects more than 60 local AI agents and the MCP servers they use on Windows and macOS, and shows which device and user each one belongs to. Agent 365 adds them to a single agent registry, and Global Secure Access spots agents from network traffic. Instead of piecing together reports from different tools, you get one inventory to start governing from. Defender discovery is GA; the registry and network discovery are in preview.

Software compliance policy for unsanctioned agents

NewHelps IT admins and end usersPublic preview

You can now treat an unapproved AI agent like any other compliance failure. You list the restricted apps (Microsoft's example uses MSI product codes), Intune marks the device noncompliant when one is found, and Conditional Access blocks work resources until the user removes it. The user is told what to remove and gets access back straight after. Test how it matches portable apps and non-MSI installs first, and start Conditional Access in report-only mode.

App protection policies for AI applications

Microsoft Copilot, GitHub Copilot, Claude and ChatGPT have built in the Intune SDK, so you can stop users copying work data out of them and selectively wipe that data. Staff get to use the AI apps they want while company data stays under your control. What each app supports can differ, so check the controls per app.

Intune policies for Microsoft Execution Containers (MXC)

NewHelps IT admins and end usersRolling out; no formal preview label

Intune policies can now decide which files, folders and network locations an agent may touch while it runs inside one. You set the rules once and Windows enforces them every time the agent runs, rather than reviewing each agent's own isolation. These policies are rolling out now and coverage will grow.

Microsoft Perception foundation and green-team agents

NewHelps IT admins and end usersGenerally available; selected agents in preview

Microsoft Perception connects security findings to actual fixes on devices. Today the security team finds a vulnerability and the endpoint team works out what to deploy; Perception's AI agents and playbooks now plan that work and run it through Intune, with an admin approving each step. Fixes happen sooner, so devices stay exposed for less time and there are fewer emergency patch nights. Perception is generally available, and its Triage Agent handles about 80% of alerts in a typical Defender queue. The Web App Pen Test Agent is in preview and the Secure AI agents playbooks are in private preview.

NewHelps IT admins and end usersLimited public preview

It takes Defender's list of risks, works out which devices and apps are affected, builds a remediation playbook covering app and Windows updates, deploys it and tracks progress. You review and approve; it saves the hours spent matching CVEs to packages and assignments. In limited public preview, in Perception's Reduce Risk Exposure playbook and in the Intune admin center for onboarded tenants.

Risk Reduction Agent

NewHelps IT admins and end usersPreview

Sometimes a patch can't go out straight away because of testing, change freezes or a vendor delay. The Risk Reduction Agent patches through Intune when a fix exists and, when it has to wait, applies temporary shielding controls to protect the device in the meantime. The temporary protection and the permanent fix are handled in one workflow. In preview. Defender calls this vulnerability shielding; it is on by default and can apply controls on its own during an active attack.

ClickFix copy-and-paste attack protection

NewHelps end usersAnnounced; stage not stated

ClickFix is a trick where a fake web page tells the user to "fix" or "verify" something by copying a command and pasting it into Run or PowerShell. Microsoft says it was behind 12.8% of the intrusions it saw this year. Defender can now detect and block these malicious paste-and-run attempts, so users are protected even if they fall for the page. Announced 17 November 2026; release stage not stated.

Windows Endpoint Security Platform

NewHelps IT admins and end usersGenerally available

Most security products run parts of themselves inside the Windows kernel, the core of the system, so one bad update can crash the whole PC. The Windows Endpoint Security Platform lets security vendors run their protection outside the kernel instead, while still protecting the device. That means fewer system-wide crashes caused by security software. Generally available on Windows 11; each vendor decides when to adopt it.

Sources: Windows security at Ignite 2026 · Building Windows for the next era of work · Endpoint-focused Ignite 2026 digest

Windows baseline protection

NewHelps IT admins and end usersPreview; Microsoft sources differ on preview type

Secure Boot, virtualisation-based security and memory integrity used to be checked one by one. Windows baseline protection rolls them into one versioned security state that the hardware can prove, so you get a simple yes or no for each device. Users can see their device's status in an updated Windows Settings page. Compliance rules get simpler, and the baseline can grow as Microsoft adds protections. Microsoft sources differ on the stage: the Book of News says private preview, the Windows IT Pro blog says Insider preview from build 26340.10013. No GA date.

Windows administrator protection

EnhancedHelps IT admins and end usersGenerally available

Local admins no longer run with admin rights all the time. They work as standard users, and when a task needs elevation, Windows Hello confirms it's really them and grants admin rights for that one task only. When the task ends, so do the rights. Malware can't quietly use standing admin access, and the elevation prompt still feels familiar. Generally available on Windows 11.

Windows declarative management

NewHelps IT admins and end usersPreview in Book of News; roadmap direction in management blog

Today Intune pushes a setting, checks it applied and fixes drift later. With declarative management you tell Windows the desired end state, and Windows applies it and keeps it that way locally, even when the device is offline. Settings like Wi-Fi and VPN are meant to apply quickly and stay protected, with clearer reporting and defined rules for conflicts. IAKerb to reduce NTLM fallback

NewHelps IT admins and end usersWindows Insider Experimental

Granular quality-update approval by update type

EnhancedHelps IT admins and end usersGenerally available

Quality update policies in Autopatch now let you approve each type of update differently. For example, auto-approve routine monthly security updates but manually approve preview or out-of-band releases. Each type has its own offer timing, deferral and pause, and the same controls cover supported .NET Framework and Quick Machine Recovery fixes. Change management gets control where it matters and speed everywhere else. Generally available.

53

Three-day security-current standard, one-day default deadline and exposure reporting

EnhancedHelps IT admins and end usersGenerally available controls and reporting

Deferrals, deadlines and grace periods can quietly add up to weeks of exposure. Microsoft now recommends devices reach the latest security update within three days. The default quality-update deadline drops to one day, and quality and feature updates can have separate grace periods. Autopatch reports flag Exposed and Critical devices, and you're warned while creating or editing update rings if your settings leave devices exposed too long. The exposure reporting is generally available; the three-day target is guidance, not a mandate, so test aggressive settings with users.

Driver update reporting

EnhancedHelps IT admins and end usersGenerally available

Stuck or failed driver rollouts are easy to spot, and you can automate checks through Graph. Generally available in Windows Autopatch.

Maintenance windows for selected update actions

Maintenance windows let you set one-time or recurring time slots and choose which update actions, such as installs or restarts, may only happen inside them. No more custom scheduling workarounds, and no surprise interruptions during working hours. Announced; Microsoft promised availability details later in November 2026.

Quick Machine Recovery management and cloud rebuild

EnhancedHelps IT admins and end usersGenerally available

When a Windows update or driver leaves PCs unable to boot, Quick Machine Recovery (QMR) can fix them remotely. QMR management through Autopatch and a new cloud rebuild option are now generally available, joining point-in-time restore and the existing rollback options. You choose the lightest recovery that fits the incident, from a targeted repair up to a full rebuild from the cloud, instead of defaulting to wipe and reimage. Users get a working device back faster.

Intune management for eligible Windows Servers

NewHelps IT adminsWindows Server Insider preview; Microsoft sources also say private/preview

Selected Windows Servers can now be managed in Intune alongside your PCs: Settings Catalog configuration, compliance, Win32 apps, remote actions, Conditional Access signals, update rings, and roles with scope tags. Windows Server 2028 platform
